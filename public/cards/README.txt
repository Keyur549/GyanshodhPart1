તમારી પોતાની Card Design (વૈકલ્પિક)
=====================================
Size: 1080 x 1350 px, PNG. આ folder (public/cards/) માં નીચેના નામથી Upload કરો.

  winner.png          -> બધા Winners (1-5 Line, Full House, Bonus, Zone) માટે એક Design
  winner-line1.png ... winner-line5.png, winner-full.png, winner-bonus.png, winner-zone.png
                      -> દરેક Winner માટે અલગ Design (ન મૂકો તો winner.png વપરાશે)
  thankyou.png        -> Thank You Card

જે file ન હોય તે માટે game ની પોતાની Design વપરાય છે.
Design માં ફક્ત Background રાખો. નામ, Zone, Avatar, સમય/Score અને Winner નું નામ
(1 Line Winner વગેરે) game પોતે ઉપર લખશે.

ક્યાં લખાશે (default): Winner label ~y430, Avatar ~y640, નામ ~y930, Zone ~y1005, સમય/Score ~y1120.
Thank You: Avatar ~y690, નામ ~y940, Zone ~y1012, Score ~y1158. એ જગ્યાઓ ખાલી/શાંત રાખો.
જગ્યા કે રંગ બદલવા: layout.example.json ની નકલ કરી layout.json માં જોઈતા ફેરફાર લખો (ફક્ત જે બદલવું હોય તે).

samples/ folder માં નમૂનાના Background છે. તેને winner.png / thankyou.png નામ આપી ઉપરના folder માં મૂકી જુઓ.
